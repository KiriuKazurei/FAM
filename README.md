# FileAutoManage（FAM）

#### 介绍
FAM是用于批量化管理文件的程序。能够应对多数量、大体积的文件查找、基础编辑。对于图像和视频，能够利用AI自动对图片增加标签辅助管理。
采用技术站

#### 软件架构
软件架构说明  
>文件搜索
>>文件搜索功能暂时选择调用EverythingSDK的功能<br/>
>>EverythingSDK能够直接搜索文件名，只要把特定文件夹下符合文件类型的文件全部搜索出来，限定文件类型后缀即可<br/>

>文件标签功能相对麻烦，需要使用SQLite数据库存储标签和文件路径<br/>
